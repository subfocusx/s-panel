# s-panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Микрозатычка без фона: `loader.exe` инжектит `taskbar.dll` только в `explorer.exe` и меняет высоту панели + размер иконок.

**Architecture:** `taskbar.dll` (MinHook, 4-5 хуков на FrameSize/IconSize/MeasureOverride) живет внутри `explorer.exe` (+1 МБ). `loader.exe` инжектит через `CreateRemoteThread+LoadLibraryW` и выходит (0 МБ фона). Конфиг — `config.ini` + реестр. Автозапуск — планировщик + вотчер перезапуска explorer.

**Tech Stack:** C++17, MSVC 14.44, Windows SDK 26100, MinHook (vendored), Win32-only, x64-only, `/MT`, без CLR.

**Spec:** `E:\Code\Software\s-panel` —对话 2026-10-21: аналог Windhawk-мода `taskbar-icon-size.wh.cpp` v1.3.10 (GPLv3), только под сборку 26100.

## Global Constraints

- Только `E:\Code\Software\s-panel`, необратимое — с подтверждением.
- Только native C++ в `explorer.exe`, C# запрещен (CLR +20 МБ).
- Цель: x64 + Windows 11 build 26100 (24H2 LTSC), одна ветка без обратной совместимости.
- Лицензия: GPLv3 (производная от Windhawk-мода).
- Память: +0.5–1.5 МБ к explorer, 0 отдельного процесса в простое, 0% CPU.

## Review Focus

- explorer.exe краш после KB-обновления (офсеты поплыли) — ожидается graceful unhook + лог.
- Антивирус/SmartScreen флаг на инжектор — ожидается unsigned-предупреждение в README.
- Вертикальная панель (слева/справа) — ожидается игнор хуков (только низ).
- Множественные мониторы / разный DPI — ожидается MulDiv по DPI.
- Перезапуск explorer.exe снимает хук — ожидается вотчер.
